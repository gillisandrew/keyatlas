# CLAUDE.md

## Project Layout

Two apps share `data/*.yaml` files:
- **Python CLI** (`src/keyatlas/`) — compiles YAML → PDF via Typst. Uses `uv`.
- **Web app** (`web/`) — TanStack Start + React + Tailwind v4. Uses `pnpm`.

## Adding a New Cheatsheet

1. Create `data/<app>.yaml` (include the schema comment: `# yaml-language-server: $schema=../schema/keyatlas.schema.json`)
2. **Manually** add the import and `raw` array entry in `web/src/data/cheatsheets.ts` — this registry is intentionally static, do not replace it with `import.meta.glob` or dynamic discovery.

For multi-file apps (like vscode-\*), use `shortname` field in each YAML to label sidebar entries; the sidebar groups by `app`.

## Do Not Edit

- `web/src/routeTree.gen.ts` — auto-generated by TanStack Router from `web/src/routes/`
- `*.pdf` — generated output, gitignored
